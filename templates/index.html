Endpoints Disponíveis:
  • POST /api/cadastrar_usuario - Cadastra um novo usuário
  • GET /api/buscar_usuario/{id} - Busca usuário por ID
  • GET /api/buscar_usuarios - Lista todos os usuários
  • DELETE /api/deletar_usuario/{id} - Deleta um usuário
  • POST /api/gerar_exercicio_personalizado/{id} - Gera exercício com IA
  • GET /api/exercicios_usuario/{id} - Lista exercícios do usuário
  • PATCH /api/concluir_exercicio/{id} - Marca exercício como concluído
  • GET /api/estatisticas - Estatísticas gerais do sistema
